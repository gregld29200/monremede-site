# Guide d'Administration - Mon Remède

## Bienvenue Oum Soumayya !

Ce guide vous explique comment utiliser votre interface d'administration pour gérer votre blog et vos recettes.

---

**Lien :** https://monremede.com/gestion-mon-remede-oum

## 1. Gérer les Articles de Blog

### Voir tous les articles

1. Cliquez sur **Blog** dans le menu
2. Vous verrez la liste de tous vos articles
3. Utilisez les filtres en haut pour afficher :
   - **Tous** : Tous les articles
   - **Publiés** : Articles visibles sur le site
   - **Brouillons** : Articles en cours de rédaction

### Créer un nouvel article

1. Cliquez sur le bouton **+ Nouvel article**
2. Remplissez les champs :

| Champ | Obligatoire | Description |
|-------|-------------|-------------|
| **Titre** | ✅ Oui | Le titre de votre article |
| **Slug** | ✅ Oui | L'adresse web (se génère automatiquement) |
| **Extrait** | Non | Résumé court pour les aperçus |
| **Contenu** | Non | Le texte complet de l'article |
| **Image principale** | Non | Photo de couverture (ratio 16:9, idéalement 1200×675px) |
| **Galerie** | Non | Photos supplémentaires |
| **Catégories** | Non | Pour organiser vos articles |
| **Article vedette** | Non | Cochez pour mettre en avant |

3. Cliquez sur **Enregistrer** (brouillon) ou **Publier**

### Modifier un article

1. Dans la liste, cliquez sur le bouton **Modifier** (icône crayon)
2. Faites vos modifications
3. Cliquez sur **Enregistrer** ou **Publier**

### Publier / Dépublier un article

- **Publier** : L'article devient visible sur le site
- **Dépublier** : L'article redevient un brouillon (invisible)

Utilisez les boutons dans la liste des articles ou dans le formulaire d'édition.

### Supprimer un article

1. L'article doit d'abord être **dépublié** (brouillon)
2. Cliquez sur le bouton **Supprimer** (icône poubelle)
3. Confirmez la suppression

> ⚠️ **Attention** : La suppression est définitive !

## 2. Gérer les Recettes

### Voir toutes les recettes

1. Cliquez sur **Recettes** dans le menu
2. Utilisez les filtres :
   - **Statut** : Tous / Publiés / Brouillons
   - **Difficulté** : Facile / Moyen / Difficile
   - **Catégorie** : Filtrer par catégorie

### Créer une nouvelle recette

1. Cliquez sur **+ Nouvelle recette**
2. Remplissez les informations :

#### Informations de base

| Champ | Obligatoire | Description |
|-------|-------------|-------------|
| **Titre** | ✅ Oui | Nom de la recette |
| **Slug** | ✅ Oui | Adresse web (automatique) |
| **Description** | Non | Présentation de la recette |
| **Image principale** | Non | Photo du plat (ratio 4:3, idéalement 1200×900px) |
| **Galerie** | Non | Photos supplémentaires |

#### Détails de la recette

| Champ | Description |
|-------|-------------|
| **Temps de préparation** | En minutes (ex: 15) |
| **Temps de cuisson** | En minutes (ex: 30) |
| **Portions** | Nombre de personnes (ex: 4) |
| **Difficulté** | Facile / Moyen / Difficile |

#### Ingrédients

Pour chaque ingrédient, indiquez :
- **Quantité** : Ex: "2 cuillères à soupe", "500g"
- **Ingrédient** : Ex: "huile d'olive", "poulet"
- **Notes** : Ex: "bio de préférence", "coupé en dés"

Cliquez sur **+ Ajouter un ingrédient** pour en ajouter d'autres.

#### Étapes de préparation

Pour chaque étape :
- **Description** : Les instructions détaillées
- **Astuce** : Un conseil pratique (optionnel)
- **Photo** : Une image de l'étape (optionnel, ratio 4:3)

Cliquez sur **+ Ajouter une étape** pour continuer.

#### Informations complémentaires

| Champ | Description |
|-------|-------------|
| **Bienfaits santé** | Les vertus de la recette |
| **Conseils** | Astuces et variantes |
| **Catégories** | Pour organiser |
| **Recette vedette** | Mettre en avant |

3. Cliquez sur **Enregistrer** ou **Publier**

## 3. Gérer les Catégories

Les catégories vous permettent d'organiser vos articles et recettes.

### Voir les catégories

1. Cliquez sur **Catégories** dans le menu
2. Vous verrez toutes vos catégories avec :
   - Le nombre d'articles
   - Le nombre de recettes
   - La couleur associée

### Créer une catégorie

1. Cliquez sur **+ Nouvelle catégorie**
2. Remplissez :

| Champ | Obligatoire | Description |
|-------|-------------|-------------|
| **Titre** | ✅ Oui | Nom de la catégorie |
| **Slug** | Auto | Adresse web (se génère tout seul) |
| **Description** | Non | Explication de la catégorie |
| **Couleur** | Non | Couleur d'affichage |

3. Cliquez sur **Créer**

### Modifier une catégorie

1. Cliquez sur **Modifier** à côté de la catégorie
2. Faites vos changements
3. Cliquez sur **Enregistrer**

### Supprimer une catégorie

1. Cliquez sur **Supprimer** (icône poubelle)
2. Confirmez

> ⚠️ **Important** : Vous ne pouvez pas supprimer une catégorie utilisée par des articles ou recettes. Retirez-la d'abord de tous les contenus.

## 4. Gérer les Images

### Image principale

Chaque article et recette peut avoir une image de couverture.

**Recommandations :**

| Type | Ratio | Dimensions idéales |
|------|-------|-------------------|
| Article de blog | 16:9 | 1200 × 675 pixels |
| Recette | 4:3 | 1200 × 900 pixels |
| Étape de recette | 4:3 | 800 × 600 pixels |

### Comment ajouter une image

1. Cliquez sur la zone d'upload (cadre en pointillés)
2. Sélectionnez votre image sur votre ordinateur
3. L'image s'affiche avec un aperçu
4. Pour changer : cliquez sur l'icône ✏️
5. Pour supprimer : cliquez sur l'icône 🗑️

### Galerie d'images

Vous pouvez ajouter plusieurs photos supplémentaires.

**Pour ajouter des images :**
1. Cliquez sur **+ Ajouter des images** ou glissez vos fichiers
2. Les images s'affichent en grille

**Pour chaque image, vous pouvez :**
- ✏️ Modifier le texte alternatif (description pour l'accessibilité)
- 🗑️ Supprimer l'image
- ↕️ Réorganiser en glissant-déposant

## 5. Publier sur Plusieurs Canaux Telegram

La section **Telegram** permet de publier un même message sur plusieurs canaux en une seule action.

### Étape 1 : Configurer vos canaux

1. Ouvrez **Telegram** dans le menu
2. Ajoutez chaque canal avec :
   - **Nom** : un libellé interne pour vous repérer
   - **Chat ID / @username** : soit `@nomducanal`, soit l'identifiant numérique du canal
   - **Description** : optionnel
3. Laissez le canal en **actif** si vous voulez l'utiliser dans les prochains envois

> ⚠️ **Important** : Le bot Telegram doit être administrateur de chaque canal avec le droit de publier des messages.

### Étape 2 : Composer le post

Vous pouvez choisir :
- **Article publié** : pour reprendre un article du blog
- **Recette publiée** : pour reprendre une recette
- **Message libre** : pour rédiger manuellement

Le formulaire pré-remplit automatiquement :
- le **titre**
- le **message**
- le **bouton**
- le **lien**
- l'**image** (si disponible)

### Étape 3 : Sélectionner les canaux

1. Cochez un ou plusieurs canaux actifs
2. Vérifiez votre message
3. Cliquez sur **Publier sur Telegram**

### Historique des envois

En bas de la page, vous verrez :
- les derniers posts envoyés
- le statut global (**Succès**, **Partiel**, **Échec**)
- le détail par canal

Cela permet d'identifier rapidement un canal mal configuré ou un problème de droit du bot.

## 6. L'Éditeur de Texte

Pour le contenu des articles, vous avez un éditeur avec des outils :

### Barre d'outils

| Bouton | Action |
|--------|--------|
| **G** | Texte en **gras** |
| *I* | Texte en *italique* |
| H2 | Titre de section |
| H3 | Sous-titre |
| • | Liste à puces |
| 1. | Liste numérotée |

### Raccourcis clavier

| Raccourci | Action |
|-----------|--------|
| `Ctrl + B` | Gras |
| `Ctrl + I` | Italique |
| `Entrée` | Nouveau paragraphe |
| `Shift + Entrée` | Retour à la ligne |

## 7. Conseils Pratiques

### Avant de publier, vérifiez :

- [ ] Le titre est clair et accrocheur
- [ ] Le slug est correct (pas de caractères spéciaux)
- [ ] L'image principale est de bonne qualité
- [ ] Le contenu est relu et sans fautes
- [ ] Les catégories sont assignées

### Bonnes pratiques pour les images

1. **Qualité** : Utilisez des images nettes et bien éclairées
2. **Taille** : Compressez les images trop lourdes (max 500 Ko idéalement)
3. **Format** : Préférez JPG pour les photos, PNG pour les illustrations
4. **Texte alternatif** : Décrivez l'image pour l'accessibilité

### Organisation recommandée

- Créez des catégories claires (ex: "Petit-déjeuner", "Remèdes naturels", "Santé digestive")
- Utilisez les mêmes catégories pour les articles et recettes liés
- Mettez en vedette vos meilleurs contenus

## 7. Questions Fréquentes

### Mon article n'apparaît pas sur le site ?

→ Vérifiez qu'il est bien **publié** (pas en brouillon)

### Je ne peux pas supprimer un article ?

→ Il faut d'abord le **dépublier** avant de pouvoir le supprimer

### Mon image ne s'affiche pas bien ?

→ Vérifiez les dimensions recommandées (voir section Images)

### Je ne peux pas supprimer une catégorie ?

→ Elle est utilisée par des articles ou recettes. Retirez-la d'abord de ces contenus.

### Comment mettre un article en avant ?

→ Cochez la case **"Article vedette"** ou **"Recette vedette"**
